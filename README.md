# Rishabh — Web Developer Portfolio

An authentic, high-fidelity portfolio website engineered for **Rishabh**, Web Developer & Software Craftsman. Inspired by the editorial studio aesthetic (Visuvate), crafted strictly with semantic HTML5, Vanilla CSS3, and Vanilla JavaScript.

## ✨ Aesthetic & Design Pillars

- **Pure Palette Fidelity**: Deep obsidian black (`#050608`), subtle slate/graphite panels (`#0a0b0f`, `#12141c`), crisp white typography (`#ffffff`), and signature Studio Deep Blue (`#0066cc`) accents.
- **Zero AI Slop & No Neon Colours**: No random magenta, cyan, or rainbow gradients. Controlled, cinematic midnight blue studio glow (`rgba(13, 56, 110, 0.42)`).
- **Luxury Editorial Typography**:
  - **Headlines**: High-contrast pairing of **Plus Jakarta Sans (800 Bold)** with *Instrument Serif (400 Italic)* for the signature `"Crafted Websites / Lasting Impressions"` treatment.
  - **UI / Inspector**: **JetBrains Mono** for developer telemetry, dimensional badges, and code snippets.
- **Interactive Studio IDE Canvas**:
  - Interactive top toolbar with viewport switcher (Desktop `1586px` vs Mobile `390px` responsive frame).
  - Left panel: Interactive layer tree (`Hero`, `Tech Stack`, `Introduction`, `Featured Works`, `Services`, `Approach`) with live active state updates.
  - Center canvas: Live artboard with simulated multiplayer cursors (`Devansh` and `Rishabh`), live bounding box inspection, and project switching.
  - Right panel: Studio Inspector with Position, Size, Typography tokens, and copyable live CSS rules.

## 🚀 Quick Start

### Development Server
```bash
npm install
npm run dev
```
Runs locally at: `http://localhost:5173/`

### Production Build
```bash
npm run build
```
Creates an optimized, minified bundle in `/dist`.

### Preview Production Build
```bash
npm run preview
```
